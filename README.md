CareerCraft Analyzer 🚀

AI-powered Resume Analyzer that provides ATS Score, Skill Gap Analysis and generates ATS-friendly resumes.

Features
- ATS Score Checker
- Skill Gap Analysis
- AI Resume Generation
- Job Description Matching
- Career Recommendations

Tech Stack
- TypeScript, CSS, HTML

How to Run
1. npm install
2. npm run dev
